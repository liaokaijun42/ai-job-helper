# AI Job Helper

This project is designed to help job seekers analyze job descriptions, evaluate role fit, identify skill gaps, and generate tailored application strategies using AI.

## Core Functions

1. Extract key requirements from a job description
2. Compare the requirements with a candidate's background
3. Identify matching strengths and missing skills
4. Generate resume keywords
5. Suggest interview preparation points
6. Assess salary, visa, and career development risks

## Target User

Early-career candidates who want to use AI to improve job search efficiency and career decision-making.
